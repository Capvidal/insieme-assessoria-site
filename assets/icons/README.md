# Ícones e favicon

Os arquivos abaixo já estão incluídos, gerados programaticamente a partir da marca da Insieme
(dois anéis entrelaçados, mesma identidade do logotipo):

- `favicon-32x32.png`
- `favicon-16x16.png`
- `apple-touch-icon.png` (180x180px)

Para substituir por uma versão definitiva (ex: a partir de um logotipo oficial em alta
resolução), gere novos arquivos com o mesmo nome em um gerador de favicon (ex:
realfavicongenerator.net) e sobrescreva os arquivos desta pasta.
